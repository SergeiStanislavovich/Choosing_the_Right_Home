# 🏠 Choosing the Right Home: EDA on Housing Prices

In this project, I explore housing price data and test the hypothesis:  
**Is there a difference in prices between houses with up to 5 floors and those with more than 5 floors?**

I conducted detailed data analysis, created visualizations, built a dashboard, and tested the hypothesis — the result might surprise you 👀

## 🎯 Goal

Conduct Exploratory Data Analysis (EDA) and identify the key features that influence housing prices.

---

## 📋 Tasks

1. Data preprocessing  
2. Statistical anomaly detection  
3. Pattern discovery  
4. Hypothesis formulation and testing  
5. Visualization and dashboard creation  

---

## 📊 Key Findings

- Features like **total area, number of rooms, living area, and kitchen area** strongly correlate with housing prices.
- Using the **Mann–Whitney U-test**, we found a **statistically significant difference** in apartment prices between:
  - 🏢 Buildings with **up to 5 floors**  
  - 🏙️ Buildings with **more than 5 floors**
